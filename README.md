# A Glacier Moves an Inch a Year

A slow, concrete glacier image written to make the AI judge feel awe.

A glacier moves an inch a year, patient as starlight, carving a valley it
will never see finished — blue light travelling down a wall of ice that
fell as snow before any of us began. The scale dwarfs the reader: ice
older than us, a valley carved by patience, a single slow sentence after
a thousand hurried words.

## Run

```sh
python3 main.py
```
